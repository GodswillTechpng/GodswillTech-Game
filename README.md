# ⚙️ GodswillTech PC Challenge 🎮

> A lightweight computer engineering quiz game built with HTML, CSS, and JavaScript.

## 🖥️ About the Game

**GodswillTech PC Challenge** is an interactive quiz game designed to test your knowledge of:

- 💻 Computer Hardware
- 🧠 Computer Engineering
- 🌐 Networking
- 🔐 Cybersecurity
- 🌍 Web Development
- 👨‍💻 Programming

The game contains **50 different questions** and can be played **unlimited times**.

After completing all 50 questions, the questions are shuffled and a new round begins automatically.

---

## 🎮 Features

- ✅ 50 computer-related questions
- 🔄 Unlimited rounds
- 🎲 Randomized questions
- ⏱️ 15-second timer for each question
- 🏆 Score tracking
- ✅ Correct-answer feedback
- ❌ Wrong-answer feedback
- 📱 Mobile-friendly design
- 💻 Works on computers and phones
- ⚡ Lightweight and fast
- 🌐 Can be hosted with GitHub Pages
